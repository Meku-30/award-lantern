# Award Lantern

航空会社・ホテルの特典の空席を、参加する人たちの PC で分けて調べるための Windows 用のアプリです。参加は招待制です。

予約・購入はしません。

## 入れ方

1. [Releases](https://github.com/Meku-30/award-lantern/releases/latest) から `award-lantern.exe` をダウンロードして起動する
2. 最初に出る説明を読んで「同意して始める」を押す
3. 招待コードを貼る

使い方は、招待のときに案内されたページの「はじめかた」にあります。

## Windows の警告が出たとき

- 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押します。
- セキュリティソフトに止められたら、無理に進めず、招待した人に知らせてください。除外の設定はしないでください。

## やめ方

- 止める: 通知領域のランタンのアイコンを右クリック →「終了」
- 消す: 設定タブの「全部消す」を押し、`award-lantern.exe` を削除する
